<threat_model>
Trust boundaries: local app state crosses into `kubectl` subprocess execution
through `CommandRunning`.

Threats:
- T-01 spoofing/wrong context: discovery accidentally uses the terminal context.
  Mitigation: every command includes `--context <contextName>` and tests assert
  exact arguments.
- T-02 information disclosure in errors: raw command output may include noisy
  cluster details. Mitigation: surface stderr as a short failure reason only;
  do not log full JSON.
- T-03 denial of service through noisy objects: historical Jobs can create a
  huge setup list. Mitigation: no `jobs` discovery command.
</threat_model>
