<threat_model>
Trust boundaries: selected context and watchlist are user-owned local state;
candidate discovery reads external cluster metadata through `kubectl`.

Threats:
- T-01 stale context mix-up: selected targets from one context appear under
  another context. Mitigation: context selection clears available candidates
  before loading the new context and never labels old candidates as current.
- T-02 selection loss: transient discovery failure deletes partial user setup.
  Mitigation: failure state preserves `selectedTargets`.
- T-03 untrusted command failure detail: full raw output leaks into setup copy.
  Mitigation: store only short failure reason from `KubectlCommandError`.
</threat_model>
