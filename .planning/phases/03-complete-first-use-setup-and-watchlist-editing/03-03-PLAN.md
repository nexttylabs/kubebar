<threat_model>
Trust boundaries: setup UI renders local state that originated from cluster
metadata. The UI must not execute commands and must not imply stale candidates
are current after failure.

Threats:
- T-01 stale candidate confusion: failed reload leaves old candidates looking
  current. Mitigation: failed state shows reason and retry; selected targets
  remain, but available candidates are not labeled as freshly loaded.
- T-02 oversized setup list: large clusters make setup unusable. Mitigation:
  namespace grouping and default collapsed groups.
- T-03 accidental deep troubleshooting UI: setup starts explaining workload
  health details. Mitigation: this plan only renders selectable candidates;
  issue #4 handles health reasons.
</threat_model>
