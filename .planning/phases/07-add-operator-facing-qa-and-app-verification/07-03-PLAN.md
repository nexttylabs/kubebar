<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generator input -> filesystem output | Shell arguments decide where generated evidence is written. |
| quality gate -> temporary artifacts | Gate creates temporary evidence for validation. |
| generated template -> human UAT | Generated rows may be copied into the committed UAT file. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | QA generator | mitigate | Generator writes static fixture/checklist content only; it does not run kubectl or mutate a cluster. |
| T-07-02 | Information Disclosure | generated kubectl failure row | mitigate | Generated content uses safe state labels and screenshot paths only; validation denies raw stderr, tokens, kubeconfig paths, full JSON, and command transcripts. |
| T-07-03 | Elevation of Privilege | generated QA docs | mitigate | Generator documents launch arguments only; it adds no app UI controls and no production state switch. |
| T-07-04 | Tampering | `swift-quality-gate.sh` temp output | mitigate | Gate uses `mktemp -d`, validates generated output, and never overwrites committed UAT or screenshot evidence. |
| T-07-05 | Information Disclosure | generated UAT template | mitigate | Generated table contains app-owned observations and paths, not raw cluster names, command transcripts, tokens, kubeconfig paths, or full JSON. |
</threat_model>
