<threat_model>
Trust boundary: the menu bar icon and docs shape user trust.

Threats:
- T-01 misleading icon: stale or failed data could look healthy.
  Mitigation: stale/failure uses a distinct symbol and accessibility label.
- T-02 accessibility gap: color-only states are unreadable for some users.
  Mitigation: state is represented by symbol and label, not color alone.
- T-03 privacy ambiguity: users may worry that Kubebar reads secrets.
  Mitigation: docs explicitly list read categories and state that secrets are
  not queried.
</threat_model>
