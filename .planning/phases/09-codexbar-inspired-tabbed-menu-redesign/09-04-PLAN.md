## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Core display data -> SwiftUI rows | Views may reorder and display fields, but health decisions and watched-row caps stay in core display logic. |
| Selected tab content -> menu shell | Overflow may scroll only selected tab content; footer actions remain reachable. |
| Local evidence -> docs | UAT and verification must not claim visible menu behavior passed without screenshot or human evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04-01 | Spoofing | `OverviewTabView`, `WatchlistSectionView` | mitigate | Attention rows appear before counters when needed; empty watched state remains a configuration issue, not healthy proof. |
| T-09-04-02 | Denial of Service | `MenuBarRootView` | mitigate | Remove fixed min content height and keep footer outside the scroll region so controls stay reachable. |
| T-09-04-03 | Information Disclosure | `09-UAT.md`, `09-VERIFICATION.md` | mitigate | Record safe summaries and app launch evidence only; do not paste raw cluster output, kubeconfig paths, or token-like values. |
| T-09-04-04 | Tampering | `HealthEvaluator` watched caps | mitigate | Add tests for ranking, healthy cap, attention cap, and hidden count. |
| T-09-04-05 | Elevation of Scope | Overview and Pods tabs | mitigate | Do not add search, filters, all-namespace inventory, live streams, provider settings, or deep troubleshooting. |
</threat_model>
