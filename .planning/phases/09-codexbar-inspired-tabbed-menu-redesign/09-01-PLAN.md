<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| kubectl data -> MenuDisplayModel | Kubernetes data has already been sanitized and shaped before SwiftUI renders it. |
| Menu tab control -> refresh services | Local tab selection must not cross into cluster-read services. |
| MenuDisplayModel -> SwiftUI views | Views consume app-owned strings and must not infer health or expose raw external output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Information Disclosure | `OverviewTabView`, `NodesTabView`, `PodsTabView`, `EventsTabView` | mitigate | Render only `MenuDisplayModel` fields and safe strings from `HealthEvaluator`; grep for raw `kubectl`, stdout, stderr, JSON, and command transcript terms. |
| T-09-02 | Tampering | `MenuBarRootView` tab selection | mitigate | Keep `selectedTab` as local SwiftUI state; add no `onChange` refresh hook and no service imports in tab views. |
| T-09-03 | Spoofing | Stale/unavailable tab states | mitigate | Render `StaleBannerView` before tab content when `display.staleBanner` exists and use explicit unavailable copy from core display fields. |
| T-09-04 | Elevation of Scope | Tab model | accept | Settings is not part of this plan and must not be added as a tab; Wave 2 handles local Settings only. |
| T-09-05 | Denial of Service | Quit action | accept | Quit is not implemented in this plan; Wave 2 handles it with app termination only. |
| T-09-06 | Information Disclosure | Future UAT evidence | transfer | Plan 03 owns UAT redaction and pending-human-verification rows. |
</threat_model>
